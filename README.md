# PRK Personal Website

A simple, modern, Apple-inspired personal website for Priyanshu Ranjan Karn (PRK).

## Files
- `index.html` — website structure and content
- `style.css` — design, responsive layout, and animations
- `script.js` — Continue button, scroll reveal animations, and current year

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload these three files.
3. In Vercel, choose **Add New Project**.
4. Import the GitHub repository.
5. Keep the default settings.
6. Click **Deploy**.

No database or backend is required for this version.
